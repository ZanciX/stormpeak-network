## Setup navodila

1. **Zaženi vsak server** enkrat da se generirajo config datoteke
2. **LuckPerms:** Kopiraj ukaze iz `luckperms-setup.txt` v konzolo
3. **NPCji (Hub):** Kopiraj ukaze iz `hub-server/npc-setup.txt` v-game
4. **AuthMe:** Deluje avtomatsko za cracked serverje
5. **Jobs (Survival):** `/jobs browse` za pregled poklicev
